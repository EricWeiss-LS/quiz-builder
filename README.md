# Luceo Quiz Builder

Builds quiz cards for Luceo Concepts: Terminology, Multiple choice, Film study and Personnel.

Open the live builder: **https://ericweiss-ls.github.io/quiz-builder/**

- `index.html` is the Quiz Builder. It is one self-contained file.
- `player-card-builder.html` is the standalone Personnel (Player Card) builder, the source that is folded into the Quiz Builder.

## Updating

Replace `index.html` and push to `main`. GitHub Pages republishes within a minute or two; people who have the page open get the new version on their next reload.

## Notes

- The **Import files → Analyze** step needs the builder to be open inside Claude. On this hosted copy it will say analysis isn't available; the **Load draft file** path works anywhere.
- Video exports are MP4 in Chrome, Edge and Safari, and WebM in Firefox.
- Team presets, saved archetypes and import drafts are stored in the browser on each person's own device.
